部署至 GitHub Pages 教學

只需 3 分鐘，即可免費將此便利貼看板上線公開存取！

本專案是完整的靜態網頁（Single HTML File），包含所有 JavaScript、CSS 與 LocalStorage 儲存邏輯，完全不需要建立後端伺服器！
  1. 儲存檔案：

    將此網頁原始碼儲存為名為 index.html 的檔案。

  2. 建立 GitHub Repository：

    前往 GitHub New Repository，建立一個全新的公開儲存庫（例如: my-sticky-board）。

  3. 上傳 index.html：

    在剛剛建立的 Repo 中，點擊 "uploading an existing file"，並上傳您剛剛儲存的 index.html 檔案，點擊 "Commit changes"。

  4. 開啟 GitHub Pages：

    進入 Repository 的 Settings ➔ 點擊左側 Pages ➔ 在 Build and deployment / Branch 選項選擇 main (或 master) ➔ 點擊 Save。

🎉 等待約 1~2 分鐘後，GitHub 就會提供給您專屬的免費網址（例如：https://your-username.github.io/my-sticky-board/）！
